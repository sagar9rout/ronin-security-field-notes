# 02 — Digital Forensics

Document evidence-led investigations and forensic lab exercises.

## Suitable topics
- File metadata and hashes
- Disk, memory, and filesystem artifacts
- Log analysis and event timelines
- PCAP/network artifact analysis
- Image and document metadata
- Evidence integrity and chain-of-custody concepts

## Writeup expectations
Preserve original evidence where possible, record hashes when appropriate, distinguish facts from hypotheses, and explain how each artifact supports a conclusion. Sanitize sensitive data before publishing.

Use the reusable writeup template in the root README.
