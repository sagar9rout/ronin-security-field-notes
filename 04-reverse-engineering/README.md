# 04 — Reverse Engineering

Document safe, authorized analysis of binaries and program behavior.

## Suitable topics
- Basic executable formats and strings
- Static analysis
- Dynamic analysis in an isolated lab
- Debugging and control-flow investigation
- File signatures and packing indicators
- Malware-analysis exercises using safe, controlled samples

## Writeup expectations
State the sample source and analysis environment, avoid executing unknown samples on a host system, and record the evidence supporting each conclusion. Never publish proprietary code or sensitive sample data without permission.

Use the reusable writeup template in the root README.
