# 03 — General Security Skills

Capture foundational skills and cross-domain security investigations that do not fit better in another category.

## Suitable topics
- Linux command-line skills
- Networking and protocol analysis
- Reconnaissance and enumeration in authorized labs
- Nmap and service identification
- Permissions, processes, and system configuration
- Scripting and security automation
- Core security concepts and lab notes

## Writeup expectations
Explain why a command or technique is useful, what its output means, and its limitations. Keep scanning and enumeration within the authorized scope.

Use the reusable writeup template in the root README.
